How To Use This Editor

1
Load Your JSON

This editor automatically tries to load your current data/portfolio-data.json. If it fails (e.g., you opened this file directly), paste your JSON into the Full JSON Editor manually.

2
Edit Content

Use the Quick Edit panels (left sidebar) for common changes, or use the Full JSON Editor for complete control over all content.

3
Validate JSON

The editor automatically validates your JSON. Errors are shown in the red bar above the editor. Always fix errors before downloading.

4
Download Updated File

Click ⬇ Download JSON to download the updated portfolio-data.json file.

5
Replace the File

Upload the downloaded file to your hosting under data/portfolio-data.json, replacing the old file. Your portfolio will reflect all changes automatically.

Common Tasks

Add a new project:

In the JSON Editor, find sections.projects.items and add a new project object following the same structure as existing projects.

Hide a section:

Use the Section Visibility panel, or find the section in JSON and set "visible": false.

Change theme color:

Use the Theme panel, or edit theme.colors.primary and theme.colors.accent in JSON.

Update resume path:

Edit site.resumePath and sections.resume.resumePath in JSON.

Add a certification:

Find sections.certifications.items and add a new object with id, title, issuer, category, description, visible: true.

Add a social link:

Find socialLinks array and add { "id": "...", "label": "...", "url": "...", "icon": "...", "visible": true }.

Change typing animation texts:

Edit personal.typingTexts array. Each string is shown in the hero typing animation.

Local Testing Note

⚠️ Opening index.html directly in a browser may block JSON loading due to browser security restrictions (CORS). Always use a local server when testing locally:

• VS Code: Right-click index.html → Open with Live Server
• Node.js: npx serve . in the portfolio folder
• Python: python -m http.server 8000
